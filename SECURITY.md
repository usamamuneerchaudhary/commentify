# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.x     | :white_check_mark: |

## Reporting a Vulnerability

Please report security vulnerabilities privately to **hello@usamamuneer.me**.

Do not open public GitHub issues for security-sensitive findings.

We aim to acknowledge reports within 2 business days and will coordinate disclosure once a fix is available.
