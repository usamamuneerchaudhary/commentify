Commentify is a Laravel Livewire comments package for any Eloquent model. Tailwind CSS and Bootstrap 5, nested replies, markdown, likes, reports, guest posting, and an optional Filament admin. PHP 8.3+, Laravel 12 or 13, Livewire 4.

The guides live at [docs.commentify.pro](https://docs.commentify.pro). This repository is the MIT package. [Commentify Pro](https://docs.commentify.pro/quickstart) adds the JSON API, React and Vue, and the moderation tools on the same tables.

## Install

Install from the [installation guide](https://docs.commentify.pro/installation).

```bash
composer require usamamuneerchaudhary/commentify
```
